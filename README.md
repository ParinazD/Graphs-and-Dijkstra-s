# Graphs Project
*By Parinaz*

- Memory-Efficient Representation: Uses an array of ArrayList objects (Adjacency List) to track node connections.
- Graph Traversals: Fully supports both Depth-First Search (DFS) and Breadth-First Search (BFS).
- Property Diagnostics: Methods to easily query the In-Degree and Out-Degree of individual nodes.
- Shortest Path Resolution: Uses a BFS-driven path-finding algorithm to efficiently compute the shortest distance between any two nodes in an unweighted layout.
